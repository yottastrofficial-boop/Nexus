# Protótipos experimentais arquivados

Os protótipos HTML abaixo eram estudos visuais isolados, não componentes executáveis do Foundry VTT. Foram retirados da árvore ativa para reduzir arquivos de versões antigas sem apagar sua história Git.

## Editor UX 1.0.0.18
- **Objetivo:** explorar visualmente a distribuição de Propriedades, Estrutura de dados e Comportamento.
- **O que demonstrava:** abas de Dados/Aparência/Avançado, edição de valor, seleção de propriedade, fluxos com gatilhos, condições e ações.
- **Limitações:** HTML/CSS estático; controles não estavam conectados ao Actor, à persistência de layouts ou ao motor de interações. Não era uma versão instalável nem uma implementação funcional.

## Editor UX 1.0.0.19
- **Objetivo:** explorar a organização de Biblioteca e Propriedades em janelas redimensionáveis.
- **O que demonstrava:** categorias da Biblioteca, painel de detalhes, cartões de assets e distribuição de propriedades.
- **Limitações:** protótipo de interface sem integração com Foundry, sem persistência e sem validação de comportamento. Não era uma versão instalável.

Os arquivos originais permanecem disponíveis no histórico Git anterior à limpeza. Não foram removidas Releases nem tags de versões publicadas.
